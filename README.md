# ¡Vamos! — разговорный испанский

Личный бесплатный некоммерческий курс для русскоязычного начинающего: 30 учебных дней по 35 минут, оригинальные записи носителей, упражнения, интервальное повторение и самостоятельная разговорная практика.

## Возможности

- 30 занятий; слух, значение, порядок слов, воспроизведение по памяти и собственный ответ.
- 196 единиц коллекции: слова в явно подписанном озвученном контексте, фразы, предложения и 12 мини-текстов.
- 12 сцен со сменой роли и скрытием своей реплики; четыре устные проверки с самооценкой.
- Подготовленные объяснения грамматики и употребления; 30 моделей предложений.
- Темп ×0,5–1,25 с сохранением высоты голоса; отдельные настройки движения, звуков, оформления и нагрузки.
- Избранное, заметки, трудные слова, выбранные наборы; экспорт и объединение прогресса JSON.
- Последовательный маршрут и календарь 30 дней; просмотр будущих уроков, свободный порядок и сохранение незавершённого шага.
- Лумо с подсказками по заданию; короткие круги воспоминания, слуха и ответа в новой ситуации.
- Проверка распознанных слов, оригинальный образец и локальная запись для сравнения. Дневная цель и история фактически выполненных действий.
- Установка на главный экран, быстрые действия, явное сохранение всех 72 аудиозаписей офлайн и необязательное удержание экрана — при поддержке браузера.

Прогресс хранится в localStorage этого браузера. Записи MediaRecorder остаются временными локальными объектами. Необязательное распознавание запускается отдельно по кнопке: сервис браузера может передавать звук своему провайдеру и требует согласия. Экспериментальный режим на устройстве требует поддержки es-ES и языкового пакета. Распознавание проверяет слова, не акцент, фонемы или уровень; результат не сохраняется. Курс не обещает свободную речь или отсутствие акцента за 30 дней.

## Запуск и публикация

Python 3: `python -m http.server 8768 --bind 127.0.0.1 --directory web`.

`python build-course-v2.py` собирает данные и HTML (название сборщика сохранено). `python build-deploy.py` собирает чистую публикацию в `docs/`. GitHub Pages публикует `main:/docs`. Все пути относительные, backend и API-ключи не нужны.

Проверки Playwright: `check-core-v5.cjs`, `check-library-v5.cjs`, `check-conversation-v5.cjs`, `check-learning-v5.cjs`, `check-state-v5.cjs`, `check-native-failure-v5.cjs`. Путь к Playwright можно задать переменной `PLAYWRIGHT_PATH`. Браузерное распознавание проверяется подменой API, микрофон — тестовым устройством; точность акустического распознавания и реальные телефоны эти тесты не подтверждают.

Офлайн: «Настройки» → «Сохранить аудио офлайн». Дождись 72/72. Первое открытие требует сети; браузер может очистить кэш при нехватке места. Для обновления установленного курса предусмотрена явная кнопка, которая сохраняет текущий учебный шаг перед перезагрузкой. На iPhone/iPad: Safari → «Поделиться» → «На экран Домой». Системные виджеты не заявляются; виджеты прогресса находятся в самом приложении.
